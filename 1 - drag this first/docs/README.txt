CRT Media Agency website
========================

To view the site, open index.html in any web browser (double-click it).
No server, hosting or installation is needed. Keep the folder together:
pages, site.css, site.js and the assets folder link to each other.

Pages:     each page is a folder with an index.html (about/, weddings/, contact/ ...)
Styles:    site.css
Behaviour: site.js  (menu, enquiry form -> WhatsApp, booking link, analytics IDs)
Images:    assets/
Settings:  crt-config.js (optional Supabase keys for the /admin dashboard)

The "Get a quote" forms open WhatsApp (+250 796 356 035) with the visitor's details filled in.
