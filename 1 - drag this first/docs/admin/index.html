    Add a team member

    1. In Supabase, open Authentication → Users → Add user → Create new user. Enter their email and a starting password, and tick Auto Confirm User.
    2. In SQL Editor, run the lines below with their name and email (use 'admin' instead of 'staff' for full access):
    insert into public.team (user_id, name, role)
select id, 'Their name', 'staff' from auth.users where email = 'their@email.com'
on conflict (user_id) do nothing;

    Give them the password privately. They sign in on this admin page (admin/index.html in the website folder). To reset a password later, open the user in Authentication → Users.
